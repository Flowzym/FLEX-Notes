# App-Hintergrund

`dark-texture.png` ist die unveränderte Nutzerdatei aus
`Background Mobile 01 Dark small.zip`, bereitgestellt am 01.11.2026.

- Originalname: `Background Mobile 01 Dark small.png`
- Abmessungen: 1061 × 1500 Pixel, PNG/RGBA
- SHA-256: `3bdab985e55e5369ca4aad8add136c37475c6d691846976630e23f22400492db`

Standard im dunklen Modus, auf Desktop und Mobil. `cover` füllt die Fläche
zentriert ohne Verzerrung; im Querformat wird das Hochformatbild beschnitten.
Die vorhandenen Bildmodi bleiben bedienbar. Eigene Bilder pro Gerät haben
Vorrang und behalten ihre bisherige Deckkraft. Ohne eigenes Bild wird die
Textur mit voller Deckkraft angezeigt. Im hellen Modus bleibt der helle Verlauf.
Das Asset liegt im App-Bundle und benötigt keinen externen Bildabruf.
